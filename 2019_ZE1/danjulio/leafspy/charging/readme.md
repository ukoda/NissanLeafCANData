## LeafSpy logfiles while charging

| File | Description |
| --- | --- |
| ```leafspy_charge_battery.crtd``` | Battery display page. |
| ```leafspy_charge_graph_AC_goes_on_off.crtd``` | AC turned on then off during charge.  Picture shows drop in charge current while AC compressor is running (second dip). |
| ```leafspy_charge_graph_histo.crtd``` | Graph page, battery voltage histogram. |
| ```leafspy_charge_graph.crtd``` | Graph page, charging power over a few seconds. |
| ```leafspy_charge_summary_chrg.crtd``` | Summary page, "Chrg" info above line bar. |
| ```leafspy_charge_summary_mph.crtd``` | Summary page, "MPH / Altitude" info above line bar. |
| ```leafspy_charge_summary_odo.crtd``` | Summary page, "Odometer" info above line bar. |
| ```leafspy_charge_summary_rpm.crtd``` | Summary page, "RPM" info above line bar. |
| ```leafspy_charge_summary.crtd``` | Summary page, "Voltage/Current/Power" info above line bar.  There are two images: ```leafspy_charge_summary1.png``` and ```leafspy_charge_summary2.png``` for this logfile. |
| ```leafspy_charge_table.crtd``` | Gauge (table) display page. |
