## LeafSpy logfiles while driving

| File | Description |
| --- | --- |
| ```leafspy_batt_idle.crtd``` | Battery display page. |
| ```leafspy_batt_temp.crtd``` | Graph page, battery temperature histogram. |
| ```leafspy_charge_graph.crtd``` | Graph page, charging power over a few seconds. |
| ```leafspy_read_ecu_versions.crtd``` | Service Menu, read ECU versions. |
| ```leafspy_summary.crtd``` | Summary page, two images associated with this logfile: ```leafspy_summary_1.png``` showing battery temps, ```leafspy_summary_2.png``` showing tire pressures. |
| ```leafspy_table_climb_regen.crtd``` | Climbing a hill and the going down the other side with regen.  Two images associated with this logfile:  ```leafspy_table_climb_regen_1.png``` showing about the maximum power during the climb and ```leafspy_table_climb_regen_2.png``` showing about the maximum regen during the descent. |
| ```leafspy_table_climb_regen2.crtd``` | Reversing the hill climb and descent. The associated image ```leafspy_table_climb_regen2.png``` shows the altitude and speed. |
