# 2017 AZE0 Nissan Leaf from danjulio

The captures here are from danjulio's USA 2017 AZE0.

They are in the [OVMS CRTD](https://docs.openvehicles.com/en/latest/crtd/index.html) log file format.

CAN Bus logs from Leafspy and of a GPS tracker I found in the car (no longer connected to its service).

## gps_tracker.crtd

`gps_tracker.crtd` is an OBD2 port log files of communication between a GPS tracker I found in the car.  Mostly just for historical record. For more information see [here](https://github.com/danjulio/can_logs/tree/main/2019_leaf_candumps/gps_tracker).

## leafspy folder

`leafspy` folder which contasins OBD2 port log files of communication between LeafSpy and the car.  See the readme in that folder for more details.  The original soure is [here](https://github.com/danjulio/can_logs/tree/main/2019_leaf_candumps/leafspy).
