# 2017 AZE0 Nissan Leaf from danjulio

The captures here are from danjulio's USA 2017 AZE0.

They are in the [OVMS CRTD](https://docs.openvehicles.com/en/latest/crtd/index.html) log file format.

Some dumps, again described in the file name, from the 2017 Leaf I parted out for my EV conversion.  One thing to note about these logs is that I had a custom traction battery communicating via a Leaf BMS emulator with the car so all battery messages are not as in a real car.

* Bus 2 : CAR CAN
* Bus 3 : EV CAN
