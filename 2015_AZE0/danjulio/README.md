# 2015 AZE0 Nissan Leaf from danjulio

The captures here are from danjulio's USA 2015 AZE0.

They are in the [OVMS CRTD](https://docs.openvehicles.com/en/latest/crtd/index.html) log file format.

Files are named after various activities in the car in order to reverse engineer communication between ECUs.  These were taken using my [CAN MIM MON]() man-in-the-middle CAN bus monitoring tool.

* Bus 1 : CAR CAN
* Bus 2 : EV CAN
